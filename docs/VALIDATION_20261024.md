Verified in MATLAB R2024a on macOS Apple Silicon. **The full dense Q search was not run.** Automated integration runs use explicitly small positive-control grids. Data supplied by the user are preserved separately from new runs of this unified package.

## Automated checks

Fourteen tests passed, including:

- FEX18593 native invocation, exact initialization/generation budgets, deterministic seeds, candidate stop and error propagation.
- SHA-256 integrity of all 38 unchanged upstream DE files.
- Default inclusive b-grid (6001 nodes), default dense Q (273034001 nodes), bijective small-grid coverage and endpoints.
- Optimized 0–1/native FFT agreement on constant, periodic and noisy 4000/5000-point series, with all coefficient errors below 1e-8.
- Optimized ConDN versus the reference trace signature and RNG preservation; block-normalized SALI versus per-step normalization at multiple short endpoints.
- Exact native nearest-neighbor indices versus brute force, including repeated points and ties.
- Short native/MATLAB integration agreement; explicit rejection of MEX with thread workers.
- Complete negative Q traversal; positive batch stopping and the optional exhaustive-positive setting.
- Duplicate cache accounting, unchanged proposals/fitness with cache disabled, completed-run reload and mid-generation native DE replay.
- Restoring a pending Q checkpoint with matching counters; censoring of discovery ratios after a failed DE search.
- Distinct estimate/full-scan reports and six-row Rosenstein-only timing with exact horizons.

A clean source-only copy without MEX binaries also passed all 12 portable tests; two optional native tests were explicitly skipped, with zero failures. The portable runner reports these skips without treating them as failures. A 16-node/one-repeat smoke call additionally checked the benchmark entry point and its common-signal component table.

The release integration script also checked two-worker Threads and Processes, serial/parallel numerical agreement, both timing profiles, repeated completed runs without counter/time changes and read-only plot reload. Compiled kernels were built with Xcode Clang++, without fast-math. Binaries are excluded from the source archive; rebuild locally.

## Reproduction

From the package root:

```matlab
build_olg_fast
results = run_tests;
addpath(fullfile(pwd,'tests'));
verify_release;          % Small integration grids and both timing profiles.
export_example_results; % Existing saved release results only; no simulations.
```

The main `paper` configuration retains the full dense grid. Neither the benchmark nor the verification examples are substitutes for a completed dense-grid search. The [October 11 report](VALIDATION_20261011.md) remains historical and uses different endpoints, Q ordering and stopping rules.
