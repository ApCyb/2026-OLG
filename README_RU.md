# Эксперименты OLG с DE из MATLAB Central File Exchange

[English](README.md) | [Русский](README_RU.md)

Пакет сравнивает DE с последовательным перебором по `b_L` до первого численного кандидата на хаос. Второй режим сравнивает время индикаторов на фиксированной траектории. Наибольший показатель Ляпунова оценивается **только методом Розенштейна**; точные якобианы используются только в дополнительном индикаторе SALI.

Алгоритм DE взят из [Differential Evolution Маркуса Бюрена, File Exchange 18593](https://www.mathworks.com/matlabcentral/fileexchange/18593-differential-evolution), **версия 1.16.0 от 13 ноября 2019 года**. Все 38 исходных файлов включены без изменений в `vendor/fex18593/`, вместе с лицензией автора. Подключение к эксперименту выполнено в `+olg/fex_de.m`. [Происхождение и лицензия](THIRD_PARTY_NOTICES.md), [контрольные суммы исходников](vendor/fex18593_manifest.json).

## Запуск

Откройте папку `olg_experiments_fex18593` как текущую папку MATLAB. Добавляйте в MATLAB path только корень пакета, без `genpath`: адаптер сам подключает внешний DE на время расчёта. Убедитесь, что MATLAB использует новую версию:

```matlab
addpath(pwd, '-begin');
which olg_config -all
which run_olg_experiment -all
```

```matlab
cfg = olg_config('compare_DE_vs_full_scan', 'paper');
result = run_olg_experiment(cfg);
```

```matlab
cfg = olg_config('compare_chaos_indicators', 'paper');
result = run_olg_experiment(cfg);
```

Проверено в MATLAB R2024a. Для параллельного поиска нужен Parallel Computing Toolbox. Исходники DE уже включены; дополнительная загрузка не требуется.

## Полная сетка начальных состояний

В обоих поисковых методах и профилях по умолчанию используется **Q = [0, 1.3] × [0, 2.1] с шагом 10⁻⁴ по обеим координатам**, включая границы: **13001 × 21001 = 273 034 001 точка на каждое значение b_L**.

По вашему условию, **для каждого b_L обходится вся сетка Q, даже после обнаружения кандидата**. Метод прекращает поиск новых значений параметра после завершения такого обхода. DE и перебор используют одинаковые сетку, порядок обхода и правила вычислений.

Хранятся только две координатные оси. Точки создаются блоками по 1024, внутри блока работает `parfor`. Сначала меняется C, затем L. Это ограничивает расход памяти, но не уменьшает число расчётов. Полный эксперимент на такой сетке — очень большой вычислительный запуск. Профиль demo сокращает только горизонты траекторий; он **не уменьшает сетку Q или сетку параметра**.

```matlab
cfg.search.Q = [0 1.3; 0 2.1];
cfg.search.stateStep = [1e-4 1e-4];
cfg.search.stateGridSize = [];       % Пусто: использовать stateStep.
cfg.search.stateBatchSize = 1024;    % Размер блока, не разрешение сетки.
```

Для короткой проверки установки можно явно задать укрупнённую сетку:

```matlab
cfg = olg_config('compare_DE_vs_full_scan', 'demo');
cfg.search.stateGridSize = [14 22];  % 308 точек, шаг 0.1.
cfg.search.maxEvaluations = 50;
result = run_olg_experiment(cfg);
```

Это отдельная проверка, а не результат на плотной сетке. Чтобы вернуть шаг 10⁻⁴, установите `cfg.search.stateGridSize=[]`. Одно лишь ограничение числа оценок параметра не уменьшает объём обхода Q.

## Параметры и DE

Фиксированы `lambda=3.01`, `sigma=1.03`, `beta=0.99`. Сетка `b_L` по умолчанию равна `1.0001:0.0001:1.6`: 6000 точек, из них 101 удовлетворяет `b_L <= 1/0.99`, а 5899 лежат выше границы. Эта аналитическая граница не используется для исключения точек или подсказки DE.

```matlab
cfg.search.bRange = [1 1.6];
cfg.search.bStep = 0.0001;
cfg.search.includeLowerEndpoint = false;
cfg.search.population = 20;
cfg.search.mutation = 0.8;
cfg.search.strategy = 7;           % DE/rand/1/bin в исходной реализации.
cfg.search.crossover = 1;           % Одна свободная координата.
cfg.search.repetitions = 1;
cfg.search.maxEvaluations = Inf;   % Ограничено числом узлов сетки b_L.
cfg.search.seed = 20261011;
cfg.filters = {'zero_one'};
% cfg.filters = {'zero_one','sali','condn'};
```

DE оптимизирует целочисленный индекс узла той же сетки b_L. Инициализация, мутация, скрещивание, ограничение параметров, отбор и переинициализация выполняются кодом Бюрена. Сохранены его правила случайной инициализации и строгого улучшения при отборе. История внешнего DE отключена, поэтому повторные предложения пересчитываются и входят в бюджет. Начальная популяция также полностью учитывается. Версия и настройки сохраняются в поле `backend` результата DE.

Адаптер останавливает внешний DE непосредственно после завершения оценки параметра с кандидатом или исчерпания бюджета, в том числе внутри начальной популяции. Он восстанавливает MATLAB path, текущую папку и состояние генератора случайных чисел. Временные файлы внешнего алгоритма удаляются. Ошибки расчёта не скрываются под видом успешной остановки.

## Горизонты и workers

| Профиль | Конец короткой траектории | Transient в поиске | Длина ряда для Розенштейна |
| --- | ---: | ---: | ---: |
| demo | 1000 | 100 | 2000 |
| paper | 5000 | 1000 | 10000 |

Все выбранные предварительные индикаторы должны пройти свои пороги до вызова Розенштейна. Пройденная часть траектории используется повторно при продолжении. Отрицательная координата немедленно останавливает траекторию; выход из Q сам по себе её не останавливает, поскольку Q задаёт только начальные состояния.

```matlab
cfg.parallel.workers = 'auto';      % Число физических ядер, с учётом размера блока.
% cfg.parallel.workers = 8;
% cfg.parallel.enabled = false;    % Без Parallel Computing Toolbox.
```

Автоматический выбор использует физические ядра на macOS и доступное число вычислительных потоков как запасной вариант. Размер пула записывается в результаты. Создание пула не входит во время поиска.

## Результаты и длительные расчёты

- `FirstCandidateEvaluation` — номер оценки параметра с первым кандидатом.
- `FirstCandidateSeconds` — время от начала метода до получения первого блока с кандидатом. Это время завершения параллельного блока, а не отдельного worker.
- `ElapsedSeconds` — полное время метода, включая оставшуюся часть Q после обнаружения, контрольные сохранения и завершение DE.
- `CandidateB` — найденное значение параметра; `FoundDuringInitialization` — найдено ли оно в начальной популяции DE.
- `Trajectories`, `OrbitSteps`, `FTLECalls` — фактические объёмы работы, включая полный обход Q после обнаружения.

`comparison.csv` содержит отношения стоимости перебора к стоимости DE. Если метод исчерпал бюджет без кандидата, показатели обнаружения равны `NaN`; это не доказательство отсутствия хаоса. Успех DE не означает нахождение минимального b_L с хаосом. Обнаружение в начальной популяции характеризует весь случайный метод поиска и само по себе не показывает пользу эволюционных обновлений.

Сохраняются агрегированные счётчики и одна траектория-свидетель. Для плотной сетки индивидуальные структуры всех 273 млн точек и полная карта бассейна не накапливаются. При числе точек до `cfg.search.retainInitialStatesMax=10000` сохраняются также индивидуальные диагностики. `result.initialStates` содержит описание сетки; `olg.state_block(result.initialStates, first, last)` восстанавливает нужный диапазон точек.

Каждый запуск создаёт новую подпапку в `results`. Во время долгой оценки параметра примерно каждые 30 секунд, на границе блока, выводится прогресс и обновляется `current_parameter.mat` с частичными агрегированными результатами. Это снимок прогресса; автоматическое продолжение прерванного расчёта не реализовано. Завершённые оценки записываются в контрольные MAT-файлы, итоговые таблицы и графики.

```matlab
result = olg_show_results('путь/к/сохранённому/запуску');
```

## Сравнение индикаторов

В режиме `compare_chaos_indicators` фиксированы `b_L=1.54` и `(C_0,L_0)=(0.5,1)`. DE и сетка Q здесь не используются. После прогрева выполняются семь последовательных измерений 0–1, SALI, ConDN и Розенштейна. Время генерации общей траектории вынесено отдельно. Transient по умолчанию равен нулю; Розенштейн использует весь ряд `C_1,...,C_H`.
